# DA7219 headset codec: register recipe

Extracted from Linux `sound/soc/codecs/da7219.c`, `da7219-aad.c` and
`sound/soc/intel/avs/boards/da7219.c`, using the C434T's ACPI `_DSD` values. Basis for
headphone / headset-mic support in C434TAudio (DSP side: `buildHeadphonePath()`, SSP1).
All registers 8-bit address / 8-bit value. Codec at I2C5 0x1A (ACPI `DLG7`, `DLGS7219`);
its interrupt (GSI 0x69) is not usable from macOS, so jack detection is polled.

## ACPI properties -> registers

| Property | Value | Register effect |
|---|---|---|
| dlg,micbias-lvl | 2600 | MICBIAS_CTRL 0x62 = 0x05 (2.6 V, enable bit3 off); first-capture delay 300 ms |
| dlg,mic-amp-in-sel | diff | MIC_1_SELECT 0x10 = 0x00 |
| aad dlg,btn-cfg | 50 | ACCDET_CONFIG_1 bits[3:1] = 0x08, only after a 4-pole plug is detected |
| aad dlg,mic-det-thr | 200 | CONFIG_1 bits[5:4] = 0 |
| aad dlg,jack-ins-deb | 20 | CONFIG_2 bits[3:1] = 0x04 |
| aad dlg,jack-det-rate | "32ms_64ms" | Current Linux does not parse this string and falls back to 256_512. Firmware intent: rate 0, so **CONFIG_2 = 0x04** |
| aad dlg,jack-rem-deb | 1 | CONFIG_2 bits[7:6] = 0 |
| aad button thresholds | 0x0A/0x16/0x21/0x3E | CONFIG_3..6 (0xC8..0xCB) |
| aad dlg,btn-avg / adc-1bit-rpt | 4 / 1 | CONFIG_7 0xCC = 0x02 |
| supplies (none in ACPI) | - | IO_CTRL 0x91 = 0x00, as Linux writes it |

## 1. Init (after a soft reset, write explicit values; Linux skips writes equal to its cache)

1. Read CHIP_ID1/2 0x81/0x82 (expect 0x23/0x93) and REVISION 0x83.
2. If SYSTEM_ACTIVE 0xFD != 0: GAIN_RAMP 0x92 = 0x01; MODES 0x50 = 0x00, 0x51 = 0x01; poll SYSTEM_STATUS 0xE0 == 0 (6 x 50 ms).
3. ACCDET_CONFIG_1 0xC6 clear bit0. CIF_CTRL 0x13 |= 0x80 (soft reset; add ~2 ms).
4. SYSTEM_ACTIVE 0xFD bit0 = 0 then 1. IO_CTRL 0x91 = 0x00.
5. If REVISION minor (bits[3:0]) == 0: REFERENCES 0x32 = 0x08.
6. MICBIAS_CTRL 0x62 = 0x05; MIC_1_SELECT 0x10 = 0x00; PC_COUNT 0x94 = 0x03.
7. MIXIN_L_CTRL 0x65 = 0x60; ADC_L_CTRL 0x67 = 0x60; DAC_L/R_CTRL 0x69/0x6A = 0x60; HP_L/R_CTRL 0x6B/0x6C = 0x64.
8. TONE_GEN_CYCLES 0xB6 = 0x07; TONE_GEN_CFG1 0xB4 = 0x00.
9. AAD: CONFIG_1 0xC6 = 0xC6; CONFIG_2 0xC7 = 0x04; CONFIG_3..6 = 0x0A,0x16,0x21,0x3E; CONFIG_7 = 0x02.
10. Hidden: 0xF0 = 0x8B, 0x75 = 0x80, 0xF0 = 0x00 (unlock, jack-insert polarity LOW, relock).
11. CONFIG_1 = 0xC0; IRQ masks 0xC4/0xC5 = 0x00.
12. REFERENCES 0x32 = 0x08 (bias on); DAI_TDM_CTRL 0x2D = 0x00; PLL_CTRL 0x20 = 0x10.
13. CONFIG_1 = 0xC1 (accessory detection on).

Suspend: CONFIG_1 bit0 = 0; 0xFB bit0 = 0; mic bias off; REFERENCES bit3 = 0. Resume: re-init.

## 2. Clocks (MCLK 24.576 MHz from the SSP, PLL in SRM to 98.304 MHz)

PLL_FRAC_TOP 0x22 = 0x00, PLL_FRAC_BOT 0x23 = 0x00, PLL_INTEGER 0x24 = 0x20,
PLL_CTRL 0x20 = 0x8C (SRM, input divide by 8). Before enabling the DAI: PC_COUNT 0x94 bit0 = 0,
then poll PLL_SRM_STS 0x25 bit7 (lock) up to 8 x 50 ms. Lock needs the SSP clocks running;
0x25 bit4 shows MCLK present. Stop: PLL_CTRL = 0x0C, PC_COUNT bit0 = 1.

## 3. DAI: I2S, codec is clock consumer, 48 kHz, 24-bit, 2 ch

DAI_CLK_MODE 0x2B = 0x01; SR 0x17 = 0x0B; DAI_CTRL 0x2C = 0x28 (0xA8 with DAI_EN while streaming).

## 4. Headphone playback

Static: MIXOUT_L/R_SELECT 0x4B/0x4C = 0x01; DIG_ROUTING_DAC 0x2E = 0x32; DAC_L/R_GAIN 0x45/0x46 = 0x6F (0 dB);
HP_L/R_GAIN 0x48/0x49 = 0x39 (0 dB); CP_CTRL 0x47 = 0x20; DAC_FILTERS5 0x40 = 0x00.

Up: GAIN_RAMP 0x92 = 0x01 -> PLL (above) -> DAI_CTRL bit7 -> CP_CTRL bit7 (40 ms) -> HP_L/R_CTRL bit7 (40 ms each)
-> DAC_L/R_CTRL bit7 (40 ms each) -> MIXOUT_L/R_CTRL 0x6E/0x6F bit7, then clear HP bit2 (MIN_GAIN)
-> restore ramp -> unmute: clear bit6 of DAC_x_CTRL and HP_x_CTRL. HP output drive (HP_x_CTRL bit3) is set by jack detection.

Down: mute (bit6), set HP bit2 (30 ms), clear MIXOUT bit7, DAC bit7 (40 ms), HP bit7 (40 ms), PLL bypass,
DAI_CTRL bit7 off, PC_COUNT bit0 = 1, CP_CTRL bit7 off.

## 5. Headset mic

Static: MIXIN_L_SELECT 0x33 = 0x01; DIG_ROUTING_DAI 0x2A = 0x00 (the default 0x10 routes the tone generator);
MIC_1_GAIN 0x39 = 0x01; MIXIN_L_GAIN 0x34 = 0x03; ADC_L_GAIN 0x36 = 0x6F.

Up: ramp 0x01, PLL, DAI_CTRL bit7, MICBIAS_CTRL = 0x0D, MIXIN_L_CTRL bit3, DAI_TDM_CTRL 0x2D bit6,
MIC_1_CTRL 0x63 bit7 (300 ms after bias first comes up), MIXIN_L_CTRL bit7 (40 ms), ADC_L_CTRL bit7,
unmute (clear bit6 of 0x63, 0x65, 0x67). Down in reverse.

## 6. Polled jack detection (accessory detection runs on the internal oscillator)

Status 0xC0: bit0 inserted, bit1 4-pole headset (valid after detection), bit3 mic bias up.
Events 0xC2: bit0 inserted, bit1 removed, bit2 detection complete; 0xC3: buttons (press bits0-3, release bits7-4).
Acknowledge events by writing the read values back.

- Insert: set 0xFB bit0 within ~30 ms.
- Detection complete: clear 0xFB bit0. Headset: set HP_x_CTRL bit3, MICBIAS_CTRL = 0x0D, CONFIG_1 = 0xC9 (buttons).
  3-pole: treat as headphones, set HP_x_CTRL bit3.
- Removal: clear HP_R then HP_L bit3, CONFIG_1 = 0xC1, MICBIAS_CTRL = 0x05, clear 0xFB bit0.
- Also track STATUS_A bit0 as a level, in case an event is missed.

Buttons (board file): A play/pause, B volume up, C volume down, D voice command.
